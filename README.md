## 단축키

### LD
![Tools_LD](가이드/Tools_LD.png)
| 단축키 | 설명 |
| :--- | :--- |
| ESC | 선택 모드로 변경 |
| F3 | 평상시 열린 접점 |
| F4 | 평상시 닫힌 접점 |
| Shift + F1 | 양(Positive) 변환 검출 접점 |
| Shift + F2 | 음(Nagetive) 변환 검출 접점 |
| F5 | 가로선 |
| F6 | 세로선 |
| F9 | 코일 |
| F10 | 응용 명령어 |

## 편집
| 단축키 | 설명 |
| :--- | :--- |
| Ctrl + E | 설명문/레이블 입력 |
| Ctrl + I | 셀 삽입(렁 단위) |
| Ctrl + T | 셀 삭제(렁 단위) |
| Ctrl + L | 라인 삽입 |
| Ctrl + D | 라인 삭제 |
| Delete/Backspace | 요소 삭제 |
| Ctrl + C | (선택 영역) 복사하기 |
| Ctrl + X | (선택 영역) 잘라내기 |
| Ctrl + V | 붙여넣기 |
| Ctrl + Z | 편집 취소 |
| Ctrl + Y | 편집 재실행 |
